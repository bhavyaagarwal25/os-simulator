Engineered OS Simulator Dashboard

Welcome to the **Operating System Simulator**. This dashboard simulates core kernel functions: CPU process scheduling, dynamic partitioning memory management, and deadlock avoidance. Built as a high-performance demonstration, it allows you to test, analyze, and compare multiple standard algorithms side-by-side.

CPU Scheduler: Round Robin, SJF (Preemptive/Non-preemptive), FCFS, and Priority.
Memory Allocator: First Fit, Best Fit, Worst Fit & Paged replacement simulation (FIFO, LRU, Optimal).
Deadlock Prevention: Banker's safety verification algorithm.
